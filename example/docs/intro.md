# Introduction

The Ardleigh Grid handbook describes how the grid is installed, operated and kept honest. It is written once in Markdown and read in two places: on this site, and as the PDF the build produces.

## Who this is for

- Operators who run a node.
- Auditors who read the ledger.
- Anyone who wants the numbers behind the claims.

:::note
The PDF is rebuilt with every site build, so it never lags the site.
:::
