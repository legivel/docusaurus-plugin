# Ledger fields

The ledger fields, in the order they are written. See the [install steps](../guides/install.md#steps) for where the ledger starts.

## The fields

| Field | Type | Meaning |
|---|---|---|
| `id` | string | The entry's id. |
| `at` | time | When it was written, in UTC. |
| `fee` | number | The fee, in grid units. |
